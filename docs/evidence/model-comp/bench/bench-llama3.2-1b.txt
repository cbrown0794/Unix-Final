Explain the difference between a process and a thread in Unix in 4 sentences.
--- RESPONSE ---
In Unix, a process is a separate instance of a program that runs concurrently with other processes, sharing the same memory space and resources. A thread, on the other hand, is a lightweight execution unit within a process that can run concurrently with other threads, executing a specific task or function. While processes share the same memory space, threads share the same program counter and local variables, allowing for efficient execution of multiple tasks simultaneously. The key difference between the two is that processes are separate entities with their own memory space, whereas threads are part of a process and share its resources.
