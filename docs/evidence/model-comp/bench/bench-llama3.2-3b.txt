Explain the difference between a process and a thread in Unix in 4 sentences.
--- RESPONSE ---
In Unix, a process is an independent unit of execution that runs on a computer, with its own memory space, resources, and system calls. A thread, on the other hand, is a lightweight process that shares the same memory space and resources as other threads within the same process. Threads are used to improve responsiveness and efficiency by allowing multiple tasks to run concurrently within a single process. In contrast, processes are isolated from each other and require their own memory space, making them more suitable for independent tasks that don't share resources.
