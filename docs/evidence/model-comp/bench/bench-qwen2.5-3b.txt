Explain the difference between a process and a thread in Unix in 4 sentences.
--- RESPONSE ---
In Unix, a process is the fundamental unit of execution. It is an instance of a program that is running and has its own memory space. A thread, on the other hand, is a lighter-weight unit of execution within a process. Unlike a process, which has its own memory space, a thread shares the memory space of its parent process. Threads allow for more efficient use of system resources by enabling multiple threads to share the same memory space, which can lead to better performance and reduced overhead compared to using multiple processes.
